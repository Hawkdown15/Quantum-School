# Input: /nfm-qs-shorts-scheduler

You don't need to type anything. Every run opens a question form:

**Form 1: the run**
- Subjects: EVS / Maths / Hindi / MAT (tick several)
- Date: auto / today / tomorrow / a date you type
- Videos: all unscheduled shorts / title search / specific IDs
- Mode: optimize + schedule + playlist / skip long videos / optimize only / schedule only

**Form 2: one per subject**
- Time window (default EVS 17:00–23:00, Maths 17:30–23:30, or type your own)
- Interval: 60 / 30 / 120 min
- Playlist: the default, an alternative, none, or a name you type
- Related video: the default long video, none, or a YouTube link you paste

**Form 3: custom inputs** (choose "None" or type your own in the Other box)
- Exact times: e.g. `EVS=17:15,18:40,21:00  Maths=19:10,22:30` (replaces the window and interval)
- Extra tags / hashtags: e.g. `tags: पर्वत, mountains  hashtags: #EVSQuiz`
- Extra description line: the WhatsApp Channel link, or any line you type
- Any other instruction: free text, e.g. "earthquake wale shorts skip karo"

Then one approval table, and it finishes everything.

**Shortcut:** type a Hinglish line after the command and the form opens with your choices already selected:
- `/nfm-qs-shorts-scheduler kal ke EVS aur Maths shorts schedule kar do`
- `/nfm-qs-shorts-scheduler aaj sirf maths, 6 baje se har 30 min, related video bhi`
